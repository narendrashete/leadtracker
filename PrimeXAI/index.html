How the numbers were made

  • Claude hours come from the timestamps in every Claude Code session log for each project folder. Pauses longer than twenty minutes are not counted.
  • Mini-apps hosted inside the Lead Tracker server were split out by the folder each session touched. Rishta Album, Mokla Divas and PrimeGem had no separable sessions, so their hours are estimated from git history.
  • Jeevikum QuoteApp hours include four months of changes after go-live, so its saving is understated.
  • Hand estimates assume one experienced full-stack developer working without AI, sized from the code that shipped (about 250 finished lines a day) and adjusted for integrations, testing and server setup.
  • Left out because they are not live: Prime AutoTrack (automobile back office), Courier and voucher prototypes, the alarm clock app, WhatsApp extractor, and one-off Excel, SQL and analysis jobs.
